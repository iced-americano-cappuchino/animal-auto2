# 유기동물 데이터 자동 수집 · 병합 · 시각화

animal.go.kr의 "입양대상동물" / "보호센터 보호동물" 두 목록을 매일 자동으로
엑셀 다운로드 → 병합 → 시각화하는 파이프라인입니다.

## 진행 순서

### 0. 준비
```bash
pip install -r requirements.txt --break-system-packages
playwright install chromium
```

### 1. 버튼 이름 확인 (최초 1회, 로컬에서 직접 실행)
```bash
python 1_inspect_page.py
```
브라우저 창이 뜨고, 콘솔에 페이지 안의 모든 버튼/링크 정보가 출력됩니다.
- "엑셀다운로드" 관련 항목의 `text`, `onclick`, `alt` 값을 확인하세요.
- 이 값을 `2_download.py`의 TODO 부분에 반영합니다 (이미 가장 흔한 케이스로
  기본값이 설정되어 있어서, 그대로 될 수도 있습니다 — 먼저 2_download.py를
  바로 실행해보고 안 되면 1단계 결과를 참고해 수정하세요).

### 2. 실제 다운로드 테스트
```bash
python 2_download.py
```
`downloads/` 폴더에 두 개의 엑셀 파일이 생기면 성공입니다.
버튼을 못 찾는다는 에러가 나면, 1단계 출력 결과를 참고해서
`2_download.py` 안의 TODO 주석 부분(방식 A/B/C 중 하나)을 실제 값으로 수정하세요.

### 3. 병합 + 시각화 테스트
```bash
python 3_merge_visualize.py
```
`outputs/` 폴더에 병합된 엑셀 파일과 차트 이미지(png) 3종이 생성됩니다.

### 4. 자동 스케줄 등록 (컴퓨터 꺼져 있어도 실행)
1. 이 폴더 전체를 GitHub 저장소에 올립니다 (private 저장소 권장 — 공공데이터라
   민감정보는 아니지만 습관적으로 private 권장).
2. `.github/workflows/daily.yml`이 이미 포함되어 있어서, 저장소에 올리기만
   하면 **매일 00:01(KST)** 에 GitHub 서버에서 자동 실행됩니다.
3. 결과는 기본적으로 저장소에 자동 커밋됩니다. 이메일/슬랙 알림을 원하시면
   말씀해주세요 — 워크플로우에 단계를 추가해드릴게요.

## 참고
- 두 파일의 컬럼 구성이 다릅니다:
  - 입양대상동물: 공고번호/접수일자/품종/성별/발견장소/특징/상태
  - 보호센터 보호동물: 위 항목 + 공고기간/기타사항/등록번호
- `3_merge_visualize.py`는 컬럼을 "공통 컬럼 유지 + 다른 컬럼은 NaN으로 채우는"
  단순 세로 병합(concat) 방식을 사용합니다. 만약 공고번호 기준으로 두 파일을
  가로로 매칭(merge)하고 싶으시면 로직을 바꿔드릴 수 있으니 말씀해주세요.
